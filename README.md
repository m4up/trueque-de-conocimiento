# Trueque de Conocimiento — sitio informativo

Estructura inicial para el sitio web de la actividad académica. En esta etapa se construirá únicamente un sitio informativo local; la plataforma funcional de intercambio académico queda fuera del alcance.

## Tecnologías

- HTML5, CSS3 y JavaScript básico.
- Materialize CSS y JavaScript enlazados desde CDN.
- Sin backend, base de datos ni servicios externos propios.

## Archivos

- `index.html`: Inicio.
- `nosotros.html`: Nosotros; incluirá propuestas de misión y visión basadas en las fuentes, y la presentación del equipo sin roles.
- `objetivos.html`: Objetivos.
- `avances.html`: Avances reales del proyecto.
- `contacto.html`: Contacto.
- `css/style.css`: personalización visual.
- `js/main.js`: interacciones de interfaz.
- `img/`: recursos separados en `logo`, `equipo`, `banners` y `avances`.

Los HTML son plantillas estructurales. Aún no incluyen el contenido de las páginas ni un logo.

## Fuentes y precisión

Consultar los documentos de referencia del proyecto antes de redactar el contenido. Las dos fuentes del proyecto no coinciden completamente en la escritura de algunos nombres, apellidos y códigos. Verificar esos datos con el equipo antes de publicarlos. No atribuir roles, no presentar el prototipo descartado como producto vigente y no describir la plataforma futura como funcional.

## Abrir en Visual Studio Code

1. Abrir Visual Studio Code.
2. Elegir **Archivo > Abrir carpeta…**.
3. Seleccionar la carpeta `trueque-de-conocimiento-web`.
4. Abrir `index.html`. Para ver cambios, abrirlo en un navegador; las referencias a Materialize CDN requieren conexión a Internet.

## Crear el repositorio en GitHub

1. Iniciar sesión en GitHub y crear un repositorio vacío con el nombre `trueque-de-conocimiento-web`.
2. En VS Code, abrir el panel **Control de código fuente** y elegir **Inicializar repositorio**.
3. Revisar los archivos, confirmar los cambios iniciales y crear el primer commit.
4. Elegir **Publicar en GitHub** o agregar la URL del repositorio remoto desde el menú de control de código fuente.
5. Antes de publicar, confirmar que el repositorio sea público o privado según las instrucciones del curso y que no incluya datos personales no autorizados.

La carpeta está preparada localmente; no se creó ni publicó un repositorio remoto.
