# Trueque de Conocimiento

Sitio web informativo para presentar la propuesta académica **Trueque de Conocimiento**, orientada a promover el aprendizaje colaborativo y el intercambio de saberes entre estudiantes.

## Contenido del sitio

- **Inicio:** presenta la propuesta y sus áreas de interés, como el apoyo académico entre pares y los recursos de estudio.
- **Nosotros:** describe el propósito del proyecto e incluye la foto del equipo y las funciones sugeridas para la presentación.
- **Objetivos:** expone el objetivo general y los objetivos específicos de la propuesta.
- **Avances:** resume el estado de desarrollo del sitio informativo y permite mostrar u ocultar detalles de las etapas.
- **Contacto:** ofrece un formulario con validación básica de nombre, correo y mensaje en el navegador. El formulario no envía ni almacena correos.

## Tecnologías

- HTML5, CSS3 y JavaScript.
- Materialize CSS y JavaScript mediante CDN.
- Estilos personalizados en `css/style.css` e interacciones en `js/main.js`.
